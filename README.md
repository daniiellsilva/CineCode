# 🎬 CineCode

Projeto desenvolvido durante meus estudos de **Java na Alura**, com foco na prática de **Programação Orientada a Objetos (POO)**.

O CineCode simula um sistema de gerenciamento de filmes, séries e episódios, permitindo cadastrar títulos, registrar avaliações, calcular duração total e aplicar filtros de recomendação.

## 🛠️ Tecnologias

* Java
* IntelliJ IDEA
* Programação Orientada a Objetos

## 📚 Conceitos praticados

* Classes e objetos
* Encapsulamento
* Herança
* Polimorfismo
* Interfaces
* Sobrescrita de métodos
* Organização em pacotes
* Reutilização de código

## 📂 Estrutura

```text
src
└── br.com.cinecode.cine
    ├── calculo
    │   ├── CalculadoraDeTempo.java
    │   ├── Classificavel.java
    │   └── FiltroRecomendacao.java
    └── modelos
        ├── Episodio.java
        ├── Filme.java
        ├── Serie.java
        └── Titulo.java
```

## 🎯 Objetivo

Consolidar os fundamentos de Java e orientação a objetos por meio de um projeto prático inspirado em um catálogo audiovisual.
